# StudentCareerAssist

A polished starter project to help students with resume writing, job search, and freelancing opportunities.

## Quick start
1. Clone the repo
   git clone https://github.com/vinayak-s-2005/student-career-assist.git
2. Install root dependencies (backend):
   npm install
3. Start backend server:
   npm run server
4. Start frontend (in a separate terminal):
   cd client && npm install && npm run dev

## Tech stack
- Frontend: React (Vite) + Tailwind CSS
- Backend: Node.js + Express
- PDF export: Puppeteer (server-side)
