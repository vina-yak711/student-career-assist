A modern, edge-to-edge, full-screen career acceleration platform tailored for engineering students and tech candidates.

---

## 🌟 Core Highlights

- 📄 **Multi-Section ATS Resume Studio**: Full-width engineering layout with live vector PDF export.
- ✉️ **AI Cold Email & Pitch Generator**: 1-click personalized recruiter & founder outreach.
- 💼 **Global Internship & Job Radar**: Instant search across remote & campus listings.
- 💰 **Student Freelance Calculator**: Hourly rates, project estimating & client proposals.
- ⚡ **Interview Prep & Roadmaps**: 50+ curated technical interview flashcards.
- 🌐 **Multilingual Ready**: Instant 1-click switching (English, Marathi, Hindi, etc.).
- 🌙 **Sleek Dark Mode & Clean Light Mode**: High-contrast, zero-lag responsive design.

## 🚀 1-Click Free Cloud Deployment

### Option 1: Deploy Frontend on Vercel (Free & Instant)
1. Go to [Vercel.com](https://vercel.com) and click **"Add New Project"**.
2. Select your GitHub repository: **`vina-yak711/student-career-assist`**.
3. Set **Root Directory** as `./` (Vercel automatically detects `vercel.json` and builds `client/dist`).
4. Click **"Deploy"** — within 60 seconds, your global URL (e.g. `https://student-career-assist.vercel.app`) is live!

### Option 2: Deploy Backend on Render (Free & Instant)
1. Go to [Render.com](https://render.com) and click **"New Web Service"**.
2. Connect repository **`vina-yak711/student-career-assist`**.
3. Set Build Command: `npm install` and Start Command: `node server/index.js`.
4. Click **"Create Web Service"**.

## 💻 Local Development

```bash
# 1. Clone repository
git clone https://github.com/vina-yak711/student-career-assist.git
cd student-career-assist

# 2. Start Backend Server (Port 4000)
node server/index.js

# 3. Start Frontend Client (Port 5173)
cd client
npm install
npm run dev
```
